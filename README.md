# Expense Tracker

# Overview

Expense Tracker is a simple Python-based application for recording and analyzing personal expenses.

The project allows users to add expenses, view recorded expenses, calculate total expenses, find the highest expense, and analyze expenses by category.

# Features

- Add an expense
- View all expenses
- Calculate total expenses
- Find the highest expense
- Analyze expenses by category
- Store expense data in a JSON file

# Technologies Used

- Python
- JSON
- VS Code

# Requirements

- Python 
- VS Code or any Python-supported interpretur

# How to Run

1. Open the project folder in VS Code
2. open a new terminal
3. run the program
4. select an option from the menu 
5. follow the instructions as displayed in the terminal
