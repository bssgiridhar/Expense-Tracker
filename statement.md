# Project Statement

## Problem Statement

Managing daily expenses manually can make it difficult to keep track of spending and understand where money is being spent. A simple program like this can help you to make it easier u can see all the expenses at once 

## Project Scope

The project focuses on recording expenses and providing basic expense analysis through a command-line Python application.

## Target Users

The application is intended for students and individuals who want a simple way to record and review their expenses.

## High-Level Features

- Add expenses
- View expenses
- Calculate total expenses
- Find the highest expense
- Analyze expenses by category
- Store expense information for later use
